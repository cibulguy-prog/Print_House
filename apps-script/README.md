# ניהול כספי הדפוס: התקנה ב־Google Sheets

## התקנה (כ־5 דקות, פעם אחת)

1. פותחים גיליון חדש ב־Google Sheets, למשל בשם "כספי הדפוס".
2. בתפריט: **תוספים ← Apps Script** (Extensions ← Apps Script).
3. בעורך שנפתח:
   - מוחקים את התוכן של `Code.gs` ומדביקים במקומו את כל הקובץ **Code.gs**.
   - לוחצים על **+** ליד "קבצים", בוחרים **HTML**, ונותנים לקובץ את השם `Index` בדיוק. מוחקים את התוכן שלו ומדביקים את כל הקובץ **Index.html**.
   - שומרים (Ctrl+S).
4. מריצים פעם אחת את הפונקציה `setup`: בוחרים `setup` ברשימה שבסרגל העליון ולוחצים **הפעלה**. Google תבקש לאשר הרשאות לגיליון: מאשרים. (אם מופיע "Google hasn't verified this app", בוחרים Advanced ← Go to... זה הסקריפט שלך.)
5. פרסום כאפליקציית אינטרנט: **פריסה ← פריסה חדשה** (Deploy ← New deployment), סוג: **אפליקציית אינטרנט**.
   - **ביצוע בתור:** המשתמש שניגש לאפליקציה (User accessing the web app)
   - **למי יש גישה:** כל מי שיש לו חשבון Google (Anyone with Google account)
   - לוחצים **פריסה** ומעתיקים את הקישור שמתקבל. זו הכתובת של המערכת.

## חיבור האתר בגיטהאב (Print_House) לגיליון

1. מדביקים את `Code.gs` המעודכן בעורך Apps Script ושומרים.
2. **פריסה ← ניהול פריסות ← עריכה (עיפרון)**: ביצוע בתור **אני**, גישה **כולם**, גרסה **חדשה** ← פריסה. הכתובת לא משתנה.
3. מעלים את `Index.html` לריפו בשם `index.html` במקום הקיים.

זהו. האתר קורא וכותב ישירות לגיליון.

## שיתוף עם הצוות (כשעובדים דרך קישור ה־Apps Script עצמו)

משתפים את **הגיליון** עם כל מי שצריך לעבוד במערכת, בהרשאת **עורך**, ושולחים לו את קישור האפליקציה. ההרשאה נקבעת לפי הגיליון: מי שאין לו גישת עריכה לגיליון לא יכול לראות או לשנות נתונים במערכת.

בכניסה הראשונה כל משתמש מאשר הרשאות פעם אחת.

## איך זה עובד

- כל טבלה היא לשונית בגיליון: לקוחות, ספקים, עבודות, מסמכים, הוצאות והגדרות.
- כל שמירה במערכת נכתבת מיד לגיליון. המערכת מתרעננת מהגיליון כל 30 שניות, כך שרואים שינויים של אחרים. אפשר גם ללחוץ "רענון".
- מספרי חשבוניות וקבלות נקבעים בשרת עם נעילה, כך ששני משתמשים לא יקבלו את אותו מספר.
- דוחות (מע״מ, רווח והפסד, תזרים, גיול חובות, כרטסת לקוח) נכתבים ללשונית "דוח · ..." בגיליון. משם אפשר להוריד Excel או PDF.
- חשבונית נפתחת בחלון חדש להדפסה או לשמירה כ־PDF. אם הדפדפן חוסם, צריך לאשר חלונות קופצים.
- בגיליון יש תפריט **מערכת כספים** עם קישור לפתיחת המערכת.

## כללים לעריכה ישירה בגיליון

- אפשר לתקן ערכים, להוסיף עמודות משלך בסוף ולסנן.
- לא משנים את הכותרות בשורה 1 ולא את עמודת **מזהה**.
- את העמודות "שורות", "תקבולים" ו"שיוך לחשבוניות" עדיף לא לערוך ידנית.
- גיבוי: קובץ ← יצירת עותק.

## עדכון גרסה

כשמקבלים קבצים מעודכנים: מדביקים אותם מחדש בעורך, ואז **פריסה ← ניהול פריסות ← עריכה (עיפרון) ← גרסה: גרסה חדשה ← פריסה**. הקישור נשאר אותו קישור.
